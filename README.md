# Программа для работы с посылками

## Описание
Проект предоставляет функционал операций с посылками (создание, редактирование, отображение, удаление), а также операции погрузки и разгрузки посылок и получение счетов по проведённым операциям.
Возможно использование консольного клиента и телеграм-бота(@parcelsLoaderBot)


## create
/create --name "Название посылки" --form "форма посылки" --symbol "символ"
    Команда создаёт новую посылку с указанным названием, формой и символом отображения.
    Пример: /create --name "Квадратное колесо" --form "xxx%nx x%nxxx" --symbol "o"
    В результате будет создана новая посылка Квадратное колесо вида:
    ooo
    o o
    ooo

## find
/find "Название посылки"
        Команда ищет посылку по названию и отображает информацию о ней.
        Пример: /find "Посылка Тип 1"

## find-all        
/find-all
        Команда отображает информацию по всем допустимым посылкам.
        Пример: /find-all

## edit
/edit "Старое имя" --name "Новое имя" --form "новая форма" --symbol "новый символ"
        Команда редактирует посылку с указанным именем.
        Пример: /edit "Квадратное колесо" --name "КУБ" --form "xxx%nxxx%nxxx" -symbol "%"
        В результате Квадратное колесо будет заменено посылкой КУБ вида:
        %%%
        %%%
        %%%

## delete
/delete "Название посылки"
        Команда удаляет посылку по её названию.
        Пример: /delete "Посылка Тип 4"

## load
/load --u "почта@mail.ru" --parcels-text "Посылка Тип 1%nПосылка Тип 2" --trucks "3x3%n6x2" --type "Одна посылка - один грузовик" --out text
        Команда для загрузки посылок с заданными размерами и стратегией в текстовом формате.
/load --u "почта@mail.ru" --parcels-file "parcels.csv" --trucks "3x3%n6x2" --type "Сначала широкие" --out json-file --out-filename "Название_файла_вывода"
        Команда для загрузки посылок с заданными размерами и стратегией в виде файлов. В файле посылки должны быть перечислены каждая с новой строки. Название файла вывода указывается без расширения (всегда json)

## unload
/unload --u "почта@mail.ru" --infile "trucks.json" --outfile "parcels.csv" --withcount
        Команда выгружает посылки из файла с подсчетом количества (опционально).
        Пример: /unload --u "почта@mail.ru" --infile "trucks.json" --outfile "parcels-with-count.csv" --withcount

## billing
/billing --u "почта@mail.ru"
        Команда отображает квитанции пользователя по его имени
        Пример: /billing --u "почта@mail.ru"
